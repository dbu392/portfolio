## Running locally

No build step is needed. Clone the repo and open `index.html` directly in a browser:

```bash
git clone https://github.com/dbu392/portfolio.git
cd portfolio
```

Then open `index.html` in your browser, or use a tool like VS Code's Live Server extension for auto-reload while editing.
